### Integration Findings

**INT-01 (Medium):** `TradeTable.js` (untracked file) reads `realizedPnl`/`amount`/`price`/`gasUsed` but API sends `pnl`/`buyCost`/`sellRevenue`/`buyGas`. **Likely false positive** — the untracked .js files appear to be stale build artifacts; committed .tsx source was verified correct in Phase 10 VERIFICATION.md. Affects: DASH-02, DB-04.

**INT-02 (Medium):** `src/api/helpers/positions.ts` line 63 uses `dex.find(d => d.dexType === trade.pool_type)` which returns the first V3 match. BSC has 2 V3 dexes (Uniswap V3 + PancakeSwap V3), so PancakeSwap V3 positions get wrong quoter address. Non-crash — falls back to stale price with `priceStale=true`. Affects: DASH-01.

**INT-03 (Low):** Chain start/stop operations are not broadcast via WebSocket. The initiating dashboard session refreshes locally, but other connected sessions don't see the update until page reload. Affects: DASH-03.
