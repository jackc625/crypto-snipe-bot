### Integration Issues

**1. partial_sell revenue invisible to downstream consumers**
- **Source:** Phase 7 exitEngine inserts `action='partial_sell'` rows into trades table
- **Gap:** Phase 3 `getPnL()` JOIN on `action='sell'` excludes `partial_sell` rows
- **Impact:** Dashboard P&L, trade history, risk daily loss calculation, and exposure tracking all omit partial sell proceeds
- **Affected:** DB-04, RISK-02, RISK-05, DASH-02
- **Severity:** Non-critical (risk checks become more conservative, which is safer)

**2. Chain start endpoint cannot re-attach factory listeners**
- **Source:** Phase 8 `chainRoutes` accepts optional `onRestart` callback
- **Gap:** `startApiServer` in bot.ts never passes the callback
- **Impact:** `POST /api/chains/:name/start` only removes chain from stoppedChains but doesn't re-subscribe to PairCreated/PoolCreated events
- **Affected:** DASH-03

**3. telegramListener.ts disconnected from multi-chain bot**
- **Source:** Phase 1 created telegramListener.ts with whitelist filtering
- **Gap:** Phase 4 rewrote bot.ts as startMultiChainBot but never imports or starts the Telegram listener
- **Impact:** Telegram alpha drop processing is entirely non-functional in the multi-chain architecture
- **Affected:** FIX-09 (whitelist implemented but unreachable)
