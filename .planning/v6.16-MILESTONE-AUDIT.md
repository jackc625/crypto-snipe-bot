### Integration Issues (Non-Blocking)

**INT-STOP-LOSS-ENV:** `STOP_LOSS_PCT` env var declared in config.ts REQUIRED_ENV_VARS (line 63) but the value is hardcoded to 25 at line 125. Setting this env var has no effect. The stop-loss functionality works correctly with the default.
- Affected: EXIT-01, EXIT-02
- Fix: `stopLossPercent: parseFloat(process.env.STOP_LOSS_PCT || '25')`

**INT-FLASHBOTS-GLOBAL:** `FLASHBOTS_AUTH_KEY` marked `required: true` in config.ts, blocking non-ETH deployments. The chain registry already handles this conditionally.
- Affected: CHAIN-05 (usability)
- Fix: Make conditional on `ENABLED_CHAINS` containing `'eth'`
