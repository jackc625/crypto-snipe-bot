Aggregation rule (D-AGGREGATION per CONTEXT.md line 67-73):
- If any gating probe (50% or 100%) returns unsafe → overall `unsafe`.
- If 1% probe returns unsafe → add to evidence.probeResults; do NOT block (advisory).
- If all gating probes safe AND tax thresholds NOT exceeded → overall `safe`.

- evidence.probeResults always populated with the 3 per-probe summaries.
