**Status:** ✅ SHIPPED 2026-05-29

## Overview

Made the bot safe to run with real money on live Ethereum mainnet by rebuilding
the broken pre-buy safety stack, adding anti-rug runtime monitoring, hardening
exit-engine live-runtime behavior, formalizing the going-live ops path, and
closing v6.16 tech debt. The headline achievement: the 6 deferred v6.16
human-verification items were closed with **real-mainnet artifacts** (Etherscan
tx hashes, DB `amount_out` rows, pino excerpts, dashboard screenshot) via a live
real-capital LADYS roundtrip on the prod wallet — "test passing on a fork" was
explicitly rejected as closure.

Multi-chain (BSC/Base/Arbitrum) honeypot-checker deploy (HONEY-04) and the
multi-chain V3 anti-rug allowlist (ANTIRUG-15) were operator-deferred to the
next milestone as an intentional ETH-first rollout (fail-closed: those chains
refuse to boot without a deployed checker address — not a silent risk).

## Milestone Summary

**Decimal Phases (inserted under D-STOP-THE-LINE):**

- Phase 21.1: V3-Buy Tax-Gate + Flashbots Inclusion Fix (inserted 2026-05-26 — blocked the 21-07 live capture)
- Phase 21.2: Calm-Gas Sell Inclusion + Exit-Engine Robustness (inserted 2026-05-27 — surfaced by the 21-07 retry)
- Phase 21.3: Buy-Leg Calm-Gas Flashbots Inclusion (inserted 2026-05-29 — surfaced by the 2nd 21-07 retry)

**Key Decisions:**

- **Option D honeypot detection** (deploy on-chain `HoneypotChecker.sol`) over vacuous-pass / `getAmountsOut` / `eth_simulateV1`-primary — owner-mandated defense-in-depth with own simulator.
- **Discriminated-union `HoneypotResult`** with fail-closed `unknown` — vacuous-pass made unrepresentable in the type system.
- **Single-listener-per-chain anti-rug WS** (not per-position) — avoids subscription-cap leaks at scale.
- **Bot-wide per-wallet nonce authority** (`withNonceLock`, composes with re-fetch-`latest`; NOT ethers `NonceManager`) — eliminates the nonce-collision/double-spend class across buys, sells, anti-rug, fallback, approvals.
- **Snipes stay PRIVATE** — no automatic public-mempool fallback for genuine snipe buys (would forfeit front-run/sandwich protection); only an explicitly-invoked operator deliberate/capture buy may go public.
- **D-EVIDENCE-BAR** — a fork-test pass never closes a deferred-item; each needs a resolvable real-mainnet artifact.
- **ETH-first rollout** — ship `ENABLED_CHAINS=eth`; carry multi-chain deploy (HONEY-04) + multi-chain V3 allowlist (ANTIRUG-15) to the next milestone (fail-closed, re-audit trigger preserved).

**Issues Resolved (capital-safety, gate-surfaced):**

The quality gates repeatedly caught money-path bugs the green unit suite missed (masked by mocking the mechanism under test):

- 21.1: CR-01 fee-ceiling/affordability bound bypassed by `max(clampedFee, market)` in all 3 strategies.
- 21.2: S-1 failed-still-held position dropped on restart; CR-01 worker re-entrant-lock deadlock; CR-02 no-double-sell phantom-hash; NF-01 stranded-position-on-fail-safe.
- 21.3: STOP-THE-LINE-06 deliberate buy left position unmonitored/rug-unprotected; CR-01 deliberate gate priced `snipeAmount` not the operator's `amountInWei` → unexitable position.
- Milestone audit: **INT-NONCE-SELL** — private SELL leg bypassed `withNonceLock` (the lone unwrapped signing site after the 21.2-12 CR-01 fix removed the worker's outer lock). Fixed inline 2026-05-29 (`submitPrivateSell` seam, RED-proven `sellNonceLock.test.ts`, full unit 759/759).
