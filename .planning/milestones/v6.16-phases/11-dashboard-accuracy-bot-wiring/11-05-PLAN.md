Three changes needed to close the chain controls blank screen:

**1. Add dexes to backend response (src/api/routes/chains.ts):**
In the GET / handler, inside the `contexts.map` callback (around line 73-101), add a `dexes` field
to the returned object. Derive it from `ctx.chain.dexes.map(d => d.name)`. Place it after the
`connection` field. The result is an array of DEX name strings like `['uniswap-v2', 'uniswap-v3']`.

**2. Update ChainStatus type (dashboard/src/types/api.ts):**
Replace the current `ChainStatus` interface (lines 58-71) with one that matches the actual backend
response shape. Remove the nested `config` object entirely. The new type should be:

```typescript
export interface ChainStatus {
  name: string;
  displayName: string;
  status: 'running' | 'stopped' | 'disconnected';
  wsConnected: boolean;
  snipeParams: {
    snipeAmount: string;
    maxCapital: string;
    minLiquidity: string;
  };
  riskLimits: {
    maxOpenPositions: string;
    maxTotalExposure: string;
    dailyLossPct: string;
  };
  exitStrategy: {
    trailingStopPct: number;
    stopLossPct: number;
    partialSellTiers: Array<{ multiple: number; percent: number }>;
    urgencyWindowMs: number;
  };
  connection: {
    rpcUrl: string;
    wsUrl: string | null;
    chainId: number;
    lastBlock: number | null;
  };
  dexes: string[];
}
```

**3. Update ChainStatusCard (dashboard/src/components/ChainStatusCard.tsx):**
Replace ALL `chain.config.*` references with the correct paths from the new type:

- `chain.config.snipeAmount` -> `chain.snipeParams.snipeAmount`
- `chain.config.maxCapital` -> `chain.snipeParams.maxCapital`
- `chain.config.dexes.join(', ')` -> `chain.dexes.join(', ')`
- `chain.config.chainId` -> `chain.connection.chainId`
- `chain.config.rpcUrl` -> `chain.connection.rpcUrl`
- `chain.config.wsConnected` -> `chain.wsConnected`
- `chain.config.latestBlock` -> `chain.connection.lastBlock`

Also reorganize the config sections in the card to match the backend grouping:
- "Snipe Parameters" section: snipeAmount, maxCapital, minLiquidity (add minLiquidity)
- "Risk Limits" section: maxOpenPositions, maxTotalExposure, dailyLossPct (from chain.riskLimits)
- "Exit Strategy" section: trailingStopPct, stopLossPct (from chain.exitStrategy)
- "Connection Status" section: rpcUrl, wsConnected, lastBlock, chainId (from chain.connection)
- "DEXes" row: chain.dexes.join(', ')

Remove the duplicate Chain ID row (currently appears in both Exit Strategy and Connection sections).
Remove the maskRpcUrl helper from ChainStatusCard -- the backend already sends masked URLs via
maskUrl(). Just display chain.connection.rpcUrl directly with a "RPC: " prefix.

the existing assertions for ethChain, add:

This validates the backend now includes dexes derived from chain.dexes[].name.
