4. `getDailyRealizedLoss` -- Realized losses in rolling 24h window for a chain (RISK-02, per D-04/D-05/D-06):
```sql
SELECT COALESCE(SUM(
    CAST(COALESCE(s.amount_out, '0') AS REAL)
    - CAST(b.amount_in AS REAL)
    - CAST(COALESCE(b.gas_cost, '0') AS REAL)
    - CAST(COALESCE(s.gas_cost, '0') AS REAL)
), 0) AS total_loss
FROM trades b
INNER JOIN trades s ON b.token = s.token AND s.action = 'sell'
WHERE b.action = 'buy'
  AND b.chain = ?
  AND s.timestamp >= ?
  AND (
      CAST(COALESCE(s.amount_out, '0') AS REAL)
      - CAST(b.amount_in AS REAL)
      - CAST(COALESCE(b.gas_cost, '0') AS REAL)
      - CAST(COALESCE(s.gas_cost, '0') AS REAL)
  ) < 0
```

**canSnipe function (per D-13 -- all 5 checks in sequence, first failure returns):**

`export function canSnipe(chainName: string, amountNative: string, maxCapitalNative: string): RiskCheckResult`

The function performs checks in this order (per anti-pattern guidance: risk gate is fast-fail, checked BEFORE expensive safety API calls):

1. **Position size check (RISK-01, per D-01/D-02):** If `riskConfig.maxPositionSize` is set, compare `parseFloat(amountNative)` against it. If the snipe amount exceeds the hard cap, return `{ allowed: false, reason: 'position_size', details: 'Position size {amountNative} exceeds max {maxPositionSize}' }`. Per D-02: reject entirely, never auto-reduce.

2. **Daily loss circuit breaker (RISK-02, per D-04/D-05/D-06/D-07):** Query `getDailyRealizedLoss` with `chainName` and `Math.floor(Date.now() / 1000) - 86400` (24h ago). The query returns `{ total_loss: number }` -- this is a negative number representing losses. Calculate the loss threshold as `-(parseFloat(maxCapitalNative) * riskConfig.dailyLossPct / 100)`. If `total_loss <= threshold` (meaning losses exceed the percentage), return `{ allowed: false, reason: 'daily_loss_limit', details: 'Daily loss on {chainName}: {abs(total_loss).toFixed(4)} exceeds {dailyLossPct}% of {maxCapitalNative}' }`. Per D-07: only halts new snipes, existing positions keep monitoring.

3. **Open positions check (RISK-03, per D-08/D-10):** Query `getOpenPositionCount` (no params). Returns `{ count: number }`. If `count >= riskConfig.maxOpenPositions`, return `{ allowed: false, reason: 'max_positions', details: 'Open positions ({count}) at limit ({maxOpenPositions})' }`.

4. **Cooldown check (RISK-04, per D-09):** Look up `lastSnipeTime.get(chainName)`. If it exists and `Date.now() - lastSnipeTime < riskConfig.snipeCooldownMs`, calculate remaining seconds and return `{ allowed: false, reason: 'cooldown', details: 'Cooldown active on {chainName}: {remaining}s remaining' }`.

5. **Total exposure check (RISK-05, per D-11/D-12):** Query `getTotalExposure` (no params). Returns `{ total: number }`. If `total + parseFloat(amountNative) > riskConfig.maxTotalExposure`, return `{ allowed: false, reason: 'exposure_cap', details: 'Total exposure ({total.toFixed(4)} + {amountNative}) would exceed cap ({maxTotalExposure})' }`.

If all 5 checks pass, log at debug level and return `{ allowed: true }`.
