Health response (Plan 01):
```typescript
GET /health -> {
  status: 'ok' | 'degraded',
  uptime: number,
  chains: Array<{ name: string, displayName: string, connected: boolean, latestBlock: number | null, wsConnected: boolean }>,
  positions: { open: number, totalExposure: number, dailyPnL: number },
  version: string
}
```

Auth (Plan 01):
```typescript
POST /api/auth/login { apiKey: string } -> { ok: true } + Set-Cookie: session=...
// 401 -> { error: 'Invalid API key. Check DASHBOARD_API_KEY in your .env file.' }
```

Positions (Plan 02):
```typescript
GET /api/positions -> {
  positions: Array<{
    tradeId: number, token: string, chain: string,
    entryPrice: number | null, currentPrice: number | null,
    pnl: number | null, buyCost: string | null, buyGas: string | null,
    buyTime: number, poolType: string, feeTier: number | null,
    exitState: {
      highWaterMark: number, trailingActivated: boolean,
      partialTiersCompleted: number[], urgencyStartTs: number,
      urgencyPct: number, originalTokenAmount: string, volatilitySamples: number[]
    } | null
  }>
}
```

Risk (Plan 02):
```typescript
GET /api/risk/exposure -> { total: number, byChain: Record<string, number> }
GET /api/risk/limits -> {
  positionLimit: { used: number, max: number },
  exposureLimit: { used: number, max: number },
  dailyLoss: { used: number, limitPct: number }
}
```

WebSocket events (Plan 01):
```typescript
{ type: 'positions_update', data: { positions: [...] }, timestamp: number }
{ type: 'trade_event', data: { ... }, timestamp: number }
{ type: 'chain_status', data: { chains: [...] }, timestamp: number }
{ type: 'notification', data: { severity: string, message: string, chain?: string, category: string }, timestamp: number }
```
