```

2. priceMultiple = currentPrice / entryPrice
3. If priceMultiple >= 2.0 -> activate trailing stop
4. Trailing stop fires when: currentPrice <= highWaterMark * (1 - effectivePct / 100)
5. Stop-loss fires when: currentPrice <= entryPrice * (1 - stopLossPct / 100)
6. Urgency fires when: urgencyMultiplier <= 0.0 (past window)
```
