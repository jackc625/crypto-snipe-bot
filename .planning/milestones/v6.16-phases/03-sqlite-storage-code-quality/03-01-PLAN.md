3. Create `src/utils/db.ts`:
   - Import Database from 'better-sqlite3', path, fs
   - Import { logger } from './logger' for startup logging
   - Read DB_PATH from process.env (NOT from CONFIG -- avoids circular dependency)
   - Default DB_PATH: path.join(process.cwd(), 'data', 'bot.db')
   - Create data directory if it doesn't exist: fs.mkdirSync(dbDir, { recursive: true })
   - Create Database instance: const db = new Database(DB_PATH)
   - Enable WAL mode: db.pragma('journal_mode = WAL') (per D-03)
   - Set synchronous = NORMAL (safe + fast for WAL)
   - Set busy_timeout = 5000 (wait for locks instead of failing)
   - Schema version via user_version pragma:
     - Check current version, if < 1, create trades table
     - Per D-06, trades table columns:
       ```sql
       CREATE TABLE IF NOT EXISTS trades (
           id INTEGER PRIMARY KEY AUTOINCREMENT,
           token TEXT NOT NULL COLLATE NOCASE,
           chain TEXT NOT NULL DEFAULT 'mainnet',
           action TEXT NOT NULL CHECK(action IN ('buy', 'sell', 'fail')),
           tx_hash TEXT,
           block INTEGER,
           timestamp INTEGER NOT NULL DEFAULT (unixepoch()),
           amount_in TEXT,
           amount_out TEXT,
           gas_cost TEXT,
           price_at_action TEXT,
           status TEXT NOT NULL DEFAULT 'pending' CHECK(status IN ('pending', 'sold', 'failed'))
       );
       CREATE INDEX IF NOT EXISTS idx_trades_token ON trades(token);
       CREATE INDEX IF NOT EXISTS idx_trades_chain ON trades(chain);
       CREATE INDEX IF NOT EXISTS idx_trades_timestamp ON trades(timestamp);
       CREATE INDEX IF NOT EXISTS idx_trades_status ON trades(status);
       ```
     - Set user_version = 1 after migration
   - Prepared statements (cached):
     - insertTrade: INSERT with named parameters @token, @chain, @action, @txHash, @block, @timestamp, @amountIn, @amountOut, @gasCost, @priceAtAction, @status
     - getTradesByToken: SELECT * WHERE token = ? ORDER BY timestamp ASC
     - updateTradeStatus: UPDATE trades SET status = ? WHERE token = ? AND status = 'pending'
     - isTokenSniped: SELECT 1 FROM trades WHERE token = ? LIMIT 1
   - Export: db, insertTrade, getTradesByToken, updateTradeStatus, isTokenSniped
   - Export closeDb function that calls db.close() (for graceful shutdown)
   - Per D-02: NO in-memory cache. All reads go through prepared statements directly.
