## Gap 2 — INT-NONCE-SELL: Private Sell Bypasses the Nonce Authority (Integration BLOCKER, capital-safety)

**`src/exitEngine.ts:873`** — `executeFullSell`'s private-escalation submission runs **outside** `withNonceLock`:

```ts
const priv = await escalatePrivateSell(txBuilder, ctx, attempts, gasMultiplier);   // ← no withNonceLock
```

- `escalatePrivateSell` (utils/txManager.ts:175) signs + broadcasts via `sendTxWithRetry` and acquires **no** lock internally (`txManager.ts`, `reconciliation.ts`, and all three MEV strategies contain zero `withNonceLock` references).
- Its buy mirror `escalatePrivateBuy` **is** wrapped at its call site (`bot.ts:558`). Every other sell signing site is wrapped (approvals 840/843, public fallback 543/552, partial sell 1473/1495). The private-sell submission is the lone exception.
- **Root cause:** the CR-01 deadlock fix (21.2-12) removed the ExitWorker's outer `withNonceLock` (exitEngine.ts:1153-1159) on the explicit premise that "each signing site is individually wrapped" (comments :1159, :1339). The private-sell site was never wrapped — so removing the outer lock **exposed** it.
- **Exposure:** a same-wallet snipe/deliberate buy (locked) concurrent with a worker-driven exit sell (unlocked) — or anti-rug racing a routine exit — can each read `getTransactionCount('latest')` before either lands and sign two txs against one nonce; one is dropped/replaced. On a live sell that is a failed/delayed exit = **capital at risk**.
- **Falsifies:** the 21.2-13/WR-01 "no signing path bypasses the lock" closure and the Phase-21.2 **STOP-THE-LINE-04-C** "no nonce-collision bot-wide" verdict (a green-suite-missed gap — the nonce-serialization tests mock the mechanism, the exact CR-01/CR-02/S-1 pattern this project has repeatedly hit).
- **Fix (small, well-understood):**
  ```ts
  const priv = await withNonceLock(ctx.wallet.address, () => escalatePrivateSell(txBuilder, ctx, attempts, gasMultiplier));
  ```
  Single-level, non-nested (approvals release before this; the worker adds no outer lock) → NON-reentrant, deadlock-safe, exact mirror of the buy at `bot.ts:558`. Add a real-path regression test (RED-proven) that a buy and a concurrent sell serialize on the wallet.
