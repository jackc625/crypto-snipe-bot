## Configuration

**Environment:**
- Configuration source: `src/config.ts` loads from `process.env` via dotenv
- Key configs required:
  - `PRIVATE_KEY` - Wallet private key for transaction signing
  - `ALCHEMY_URL` - RPC endpoint for Sepolia (testnet)
  - `TELEGRAM_API_ID` - Telegram API credentials
  - `TELEGRAM_API_HASH` - Telegram API credentials
  - `TELEGRAM_SESSION` - Telegram session string (generated by auth.ts)
  - `TELEGRAM_BOT_TOKEN` - Telegram bot token for alerts
  - `TELEGRAM_CHAT_ID` - Telegram chat ID for notifications
  - `FLASHBOTS_AUTH_KEY` - Flashbots relay authentication key

**Build:**
- `tsconfig.json` - TypeScript configuration (ES2022 target, commonjs module)
- `tsconfig.bot.json` - Specialized config for bot compilation
- `hardhat.config.ts` - Hardhat configuration for contract deployment and testing
