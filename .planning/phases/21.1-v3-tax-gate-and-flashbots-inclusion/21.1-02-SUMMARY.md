## Accomplishments

### Task 1 — the shared helper (`src/utils/mevStrategies/reconciliation.ts`, ~430 lines)
- **`reconcileInclusion`** (D-RECONCILE-RECEIPT, RESEARCH §Q3/Q4/Q5): receipt-primary, nonce-corroborating bounded probe. `getTransactionReceipt(signedTxHash)` first → `status===1` `included` (returns real hash), `status===0` `reverted`. On a null receipt, reads `getTransactionCount(wallet.address, 'latest')` (NEVER `'pending'`) and applies the off-by-one table exactly: `latest === submittedNonce` → keep polling then `'not-landed'`; `latest > submittedNonce` with no receipt after the window → `'landed-not-ours'`. Manual `while (Date.now() < deadline)` poll with its OWN `pollMs` sleep (not the provider's pollingInterval), plus a `latest < submittedNonce` anomaly log (project memory: don't dismiss anomalies).
- **`submitWithReconciliation`** (D-NONCE-SAFE-RETRY, replaces base+attempt entirely): at the START of each attempt re-fetches `getTransactionCount('latest')` as THIS attempt's nonce; if it advanced past the PREVIOUS attempt's submitted nonce → STOPS and reconciles the previous signed hash **without resubmitting** (the double-spend guard). On `nativeConfirmed` returns the hash (strategy keeps its own included-path op log). Else reconciles over the window: `included`→`op:'mev.reconcile.included'` + real hash; `reverted`→alert+`op:'mev.reconcile.mined-but-reverted'`+throw (no same-nonce resubmit); `landed-not-ours`→alert+`op:'mev.reconcile.landed-not-ours'`+throw; `not-landed`→escalate unless ceiling/maxRetries hit → alert+`op:'mev.escalation.ceiling-hit'`+remediation pointer+throw.
- **`computeAffordablePriorityFee`** (D-FEE-ESCALATION, RESEARCH §Q7): clamps the escalated `maxPriorityFeePerGas` to `min(MEV_MAX_PRIORITY_FEE_GWEI, affordabilityBound)` where `affordabilityBound` always reserves `sellGasLimit × (baseFee×1.5 + priorityFeeCeiling)` (when `reserveSellGas`). If attempt-0 can't afford the reserve → `op:'mev.escalation.unaffordable'` + alert + throw BEFORE submitting (Pitfall 7 — never strand the exit). The 1.5× sell base-fee buffer is applied via the reused `applyGasMultiplier` (no reimplemented fee math).
- **`buildReconcileConfig(env, sellGasLimit)`**: single env→`ReconcileConfig` parse point with RESEARCH §Q7 generous defaults (45000 / 4000 / 5gwei / 1gwei / true); gwei→wei via `parseUnits`. Non-numeric/empty → default (never NaN); `MEV_RESERVE_SELL_GAS` only `'false'` disables.
- ethers v6 ONLY (no banned v5 patterns — guard green); type-only ethers imports; `applyGasMultiplier` imported from `./types`.
- Flipped 3 helper-logic stubs GREEN with tiny 50ms/10ms window/poll (Pitfall 5): nonce-advanced-stop (#2 double-spend), receipt-status===0-throw (#4 mined-but-reverted), attempt-0-unaffordable-throw (#5 stranded-exit). Each asserts the submit primitive call count + the structured `op:` + the `alert` call.

## Decisions Made
- **Absolute-gwei fee STEP over a multiplier** for per-retry escalation — RESEARCH §Q7 explicitly offers both ("escalating multiplier ... OR add an absolute-gwei step"); the step maps 1:1 to the operator-facing `MEV_PRIORITY_FEE_STEP_GWEI` knob and is clearer. The plan's `key_link`/grep gate requiring `applyGasMultiplier` from `./types` is satisfied by reusing it for the sell-reserve base-fee 1.5× buffer (genuine fractional-bigint reuse, not a token-only import).
- **`buildReconcileConfig` lives in `reconciliation.ts`** (planner's discretion per the Task 1 action): keeps the helper self-contained and gives the config tests one observable parse point. The strategies populate `cfg` from env in 21.1-04.
- **Test hoisting fix:** the SUT (`reconciliation.ts`) calls `logger.child()` at module top-level, which executes the hoisted `vi.mock('.../logger')` factory at import time. A static import of the helper tripped a TDZ `ReferenceError` on the module-scope `logInfo` let. Fixed by importing the runtime functions via a lazy `await import()` inside each test (types stay static/erased) — the exact idiom `flashbotsBundleHash.test.ts` uses for the strategy.
- **Config tests expanded 5→10** (override + default per var) to rigorously satisfy "asserts the var controls behavior (default vs override)"; all 5 stubs are un-skipped.
