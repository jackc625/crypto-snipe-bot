## Pattern Assignments

### `src/utils/nonceAuthority.ts` (NEW — per-wallet serialization mutex, D-NONCE-AUTHORITY-ALL)

**Analog:** `src/utils/exitManager.ts` (the synchronous check-and-set `Map` mutex idiom). The new module is an *async promise-chain* mutex (the existing one is a synchronous boolean lock), but the keying convention (`.toLowerCase()`, single-threaded-JS atomicity comment) and the "module-level `Map` singleton" home are copied directly.

**Sell-lock idiom to copy** (`exitManager.ts:14-25` — the atomicity reasoning + lowercase key + module-level Map):
```typescript
// JavaScript is single-threaded. ... The check-and-set on the Map is
// synchronous and atomic within a single event loop tick.
const sellingTokens = new Map<string, boolean>();
export function tryAcquireSellLock(chainOrToken: string, tokenAddress?: string): boolean {
    const key = tokenAddress ? `${chainOrToken}:${tokenAddress.toLowerCase()}` : chainOrToken.toLowerCase();
    if (sellingTokens.get(key)) return false;
    sellingTokens.set(key, true);
    return true;
}
```

**Re-fetch-'latest'-per-attempt scheme to COMPOSE WITH, not replace** (`reconciliation.ts:369-371`):
```typescript
for (let attempt = 0; attempt <= cfg.maxRetries; attempt++) {
    // (1) Re-fetch 'latest' as THIS attempt's nonce (D-NONCE-SAFE-RETRY).
    const nonce = await provider.getTransactionCount(wallet.address, 'latest');
```
> The mutex guarantees no two signing ops run concurrently for one wallet; the op *inside* the lock still re-fetches `'latest'` per attempt. Do NOT use ethers `NonceManager` (it predicts/caches nonces — the opposite of this scheme). RESEARCH §Q4 pins the signature `withNonceLock(walletAddress, op)`; the promise-chain skeleton is RESEARCH Pattern 1.

**Apply lock at every signing site:** `bot.ts:419` (buy submit), `exitEngine.ts:501` (exit sell), the new public fallback, `ensureApproval` (`exitEngine.ts:479`/`:482`), and the anti-rug sell (which already routes through `executeFullSell`).

**And the `.unref()` force-exit timer** in `bot.ts:1401-1404` (the same `setTimeout(...).unref()` posture the timeout helper uses so it never keeps the loop alive). ### `src/bot.ts` — two-stage SIGINT (modified `:1396-1445`, D-SIGINT-TWO-STAGE)

**Analog:** the existing `gracefulShutdown` — **REPLACE it, do NOT augment** (RESEARCH Candidate-Escalation #3: a second force-exit timer would compete with the parked loop).

```typescript
let shuttingDown = false;
function gracefulShutdown(signal: string): void {
    if (shuttingDown) return;                                   // ← becomes: 2nd signal → process.exit(130)
    shuttingDown = true;
    setTimeout(() => { log.error('Force exit after 5s timeout'); process.exit(1); }, 5000).unref();  // grace timer
    // ... clearAllTimers(); destroy ws providers; closeDb(); ...

process.on('SIGTERM', () => gracefulShutdown('SIGTERM'));
process.on('SIGINT', () => gracefulShutdown('SIGINT'));
```
> Two-stage shape (RESEARCH §Code Examples): first signal → graceful + arm `setTimeout(force-exit).unref()` over `SIGINT_GRACE_MS` (~8s); second signal OR grace-timeout → `process.exit()`. Keep the `clearAllTimers()` / ws-destroy / `closeDb()` cleanup body. Safe to abandon an in-flight submit (D-PERSIST-FAILED-HELD restart-resume + D-NONCE-AUTHORITY-ALL recovery).

**Source:** `exitEngine.ts:572` — `e instanceof Error ? e.message : String(e)`
**Apply to:** every new catch touching a Flashbots `bundle.wait()` path (it rejects with a bare string — RESEARCH Finding B root cause).

**Apply to:** the independent sell ceiling (clamp still binds) and the entry gate (reserve the GUARANTEED public exit).

**Apply to:** all new fee/gas math (sell ceiling, entry-gate buffer, watchdog gas). Do NOT use float math.

### `.unref()`'d safety timer
**Source:** `bot.ts:1401-1404` — `setTimeout(..., ms).unref()` so it never blocks process exit
**Apply to:** `withTimeout.ts`, the two-stage SIGINT grace timer, the watchdog budget timer.

### Composite-key Map keyed `chain:token` / wallet lowercase
**Source:** `exitManager.ts:19-21`, `detector.ts` registry keying
**Apply to:** the per-position lock (`chain:token`), the nonce authority (`wallet.address.toLowerCase()`).
