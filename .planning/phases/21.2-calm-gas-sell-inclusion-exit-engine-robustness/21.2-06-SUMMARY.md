# Phase 21.2 Plan 06: Calm-Gas Sell Inclusion Ladder Summary

The exit now escalates a sell PRIVATELY with the independent sell-leg ceiling (reason-aware attempt counts), runs a dual no-double-sell guard (reconcileInclusion + re-fetched balanceOf), then falls back to a guaranteed nonce-locked fee-on-transfer-safe public-mempool sell with reason-aware slippage — making a double-sell impossible (LADYS regression green).

## What Was Built

`executeFullSell` (src/exitEngine.ts) gained the Finding A inclusion ladder, replacing the single private `sendTxWithRetry` submit:

1. **Private escalation (D-FALLBACK-TRIGGER):** `escalatePrivateSell(txBuilder, ctx, attempts, gasMultiplier)` (new in `txManager.ts`) runs the private leg with a reason-aware attempt budget — `anti-rug -> 1` quick attempt (the rug is happening NOW), routine (`trailing-stop`/`stop-loss`/`urgency-market-sell`) -> `MEV_SELL_FALLBACK_ATTEMPTS` (default 2). It normalizes a not-landed outcome into a structured `PrivateSellResult { landed, txHash?, lastSignedHash?, lastNonce? }` (it does NOT throw on not-landed) so the ladder can fall through to the public fallback — the GUARANTEED inclusion lever. The deterministic `lastSignedHash`/`lastNonce` are captured by locally populating+signing the sell tx (the 21.1 block-independent `signedTxHash` discipline) WITHOUT broadcasting, so the engine can reconcile the exact attempt. The independent sell ceiling still flows through `submitWithReconciliation`'s affordability clamp (CR-01 unchanged — try harder, never overspend).

2. **No-double-sell guard (D-FALLBACK-NO-DOUBLE-SELL):** before any public sell — (a) `reconcileInclusion(lastSignedHash, lastNonce, ...)` on the last private attempt; if `outcome === 'included'` the private bundle landed late (the LADYS / STOP-THE-LINE-02 false-negative class) -> ABORT the public fallback and treat it as a landed sell; (b) otherwise re-fetch `balanceOf` (the authoritative truth) — if `0` -> abort (already sold), else sell ONLY the re-fetched held amount.

3. **Public-mempool fallback (D-EXIT-INCLUSION):** `executePublicFallbackSell` promotes the mainnet-proven `recover-sell-ladys.ts` logic into the engine — fresh `getAmountsOut` quote -> reason-aware `minOut` (routine reuses configured ~5% exit slippage; anti-rug widens, default 15%, floored at 10%) -> `swapExactTokensForETHSupportingFeeOnTransferTokens` (fee-on-transfer-safe). The approval AND the swap each run inside `withNonceLock(ctx.wallet.address, ...)`; the private-leg approval was also wrapped in `withNonceLock` (D-NONCE-AUTHORITY-ALL — EVERY signing site).

The public fallback is an ENGINE PATH, not a bypass flag (D-ROLLBACK) — there is no feature/escape-hatch flag. Every fallback/abort/ceiling path emits a dotted `op:` + `sendCtxAlert` with a remediation pointer (D-ALERTS), and the `e instanceof Error ? e.message : String(e)` bare-string guard is preserved (Flashbots `bundle.wait()` rejects with a bare string).

New env knob `MEV_SELL_ANTIRUG_SLIPPAGE_PCT` (default 15) registered in `config.ts` `REQUIRED_ENV_VARS` (`required:false`) and `.env.example` with default + 1-line desc (D-ENV-EXAMPLE). The other Finding A knobs (`MEV_SELL_MAX_PRIORITY_FEE_GWEI`, `MEV_SELL_FALLBACK_ATTEMPTS`) were already registered by Wave 2 (21.2-04).

### Design Decision (in-scope, no permission needed)

`escalatePrivateSell` lives in `txManager.ts` and pre-signs the sell tx LOCALLY to derive the deterministic signed-tx hash + nonce for the no-double-sell guard, then dispatches the real submit via the existing `sendTxWithRetry` strategy path. This keeps the `MevStrategy` interface UNCHANGED (no ripple to the three strategies or the 21.1 tests) while still giving the engine-level guard a reconcilable handle — chosen over the more invasive alternative of widening `MevStrategy.sendTransaction`'s return type across all strategies (D-QUALITY-FIRST: the safer, lower-blast-radius option).
