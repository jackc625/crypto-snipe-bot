<objective>
Create the `withTimeout(op, ms, label)` RPC-call timeout wrapper (Finding B layer 3) and register
the three Finding B env knobs. ethers v6 has NO reliable per-RPC-call abort (`FetchRequest.timeout`
does not abort an in-flight request — issues #4122 / #4765), so the wrapper frees the AWAITING code
path deterministically via `Promise.race([op(), timeoutReject])`. The timeout timer is `.unref()`'d
so it never keeps the process alive, and is cleared in `finally`. This is the primitive the
watchdog (21.2-09) and provider-call sites lean on so nothing hangs indefinitely on the parked
event loop.

This plan also OWNS the Finding B env registration (`RPC_TIMEOUT_MS` ~15s, `WATCHDOG_BUDGET_MS`
~60s, `SIGINT_GRACE_MS` ~8s) in `config.ts` + `.env.example` per D-ENV-EXAMPLE, so plan 21.2-09
(watchdog + two-stage SIGINT) consumes them without re-touching config.ts.

Purpose: deterministically bound any long/hung provider call (Finding B defense layer 3).
