<objective>
Fix the capital-safety bug (Finding D, D-FAILED-EXIT-KEEP-MONITORING + D-BALANCE-IS-TRUTH +
D-PERSIST-FAILED-HELD): the `executeFullSell` catch (`exitEngine.ts:561-573`) currently treats a
FAILED exit the SAME as a successful close — `updateTradeStatus('failed')` + `clearAllTimersForToken`
+ `deleteExitState` + `unsubscribeAntiRug` — stripping rug protection from a STILL-HELD position (the
LADYS evidence: 252,930,777 LADYS confirmed held AFTER the reported failure). This corrects a
MISapplication of Phase 19 D-TERMINATION (which always meant "tear down when the position CLOSES");
it is NOT a reversal.

The fix: on BOTH the success path AND the catch, the teardown decision is made by a re-fetched
on-chain `balanceOf` (the only signal that didn't lie). `<= dust` (relative to the original token
amount) → genuine close → run the existing `:551-556` teardown. `> dust` → still held → persist
`exit_failed_held` + increment `exit_failure_count` (DB v7 from 21.2-03), KEEP anti-rug registered,
and KEEP/RE-ARM the routine poll timer. After N=5 consecutive ROUTINE failures, pause routine retries
+ hard-alert; anti-rug emergency exits STILL fire (they bypass the routine-pause).

THREE research refinements MUST be covered explicitly here:
1. **executePartialSell** (`:684-690`) shares the "submit-report may lie" class — confirm it inherits
   the no-double-sell + balance-truth posture and leaves the position open (anti-rug NOT torn down).
2. **Re-arm the routine poll timer (MOST IMPORTANT):** the anti-rug exit clears the poll timer BEFORE
   `executeFullSell` (`exitTrigger.ts:222`). If that exit then FAILS on a still-held position, Finding D
   must not only KEEP anti-rug registered — it must also RE-ARM the routine poll timer so the position
   keeps being monitored/retried. A still-held position after ANY failed exit ends with BOTH.
3. **Invert antiRugReason.test.ts Test 6** — it currently ASSERTS the bug (error path calls
   unsubscribeAntiRug). Rewrite it to assert keep-monitoring; keep Tests 4/5 (genuine close tears down)
   and Test 7 (partial sell leaves position open).
