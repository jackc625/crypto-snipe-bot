# Phase 21.2 Plan 04: Calm-Gas Sell Inclusion (Finding A — Independent Sell Ceiling + Public-Exit Reserve) Summary

**The EXIT (sell) leg now bids on its own independent 25-gwei priority-fee ceiling (decoupled from the 5-gwei buy ceiling) while the affordability bound STILL clamps the final bid, and the affordability reserve was retargeted from the private CEILING priority fee to the GUARANTEED normal-priced public exit — fixing the calm-gas thin-wallet trap that left a tiny no-MEV-value exit bundle uncluded.**

## Accomplishments
- `buildReconcileConfig` is leg-aware: the SELL leg reads `MEV_SELL_MAX_PRIORITY_FEE_GWEI` (default 25), the BUY leg keeps `MEV_MAX_PRIORITY_FEE_GWEI` (default 5). The Finding A root trap — the sell reusing the 5-gwei buy cap — is closed.
- The CR-01 invariant is preserved and proven at a 10x market rate: with a 25-gwei sell ceiling but an 8-gwei affordability bound, `computeAffordablePriorityFee` returns 8 gwei (the clamp wins). The higher ceiling raises the ceiling INPUT only.
- The affordability reserve now targets the GUARANTEED public exit (`sellGasLimit x baseFee x SELL_GAS_BASEFEE_BUFFER`, a normal-priced tx) via the new exported `computePublicExitReserveWei` — dropping the over-reserving / mis-targeting private `+ ceilingWei` term.

## Decisions Made
- **Leg selection via optional trailing param, not a sibling function:** see frontmatter `key-decisions`. One parse point, zero churn to the 3 strategy callers.
- **Reserve as an exported pure helper:** single source of truth so the 21.2-08 entry gate and the runtime affordability clamp provably agree.
- **Optional `approvalGasLimit` (default 0n):** lets the entry gate reserve a one-time public-sell approval without touching the MEV-strategy call sites.
- **All four knobs co-located in config.ts here:** including `MEV_SELL_FALLBACK_ATTEMPTS` (consumed by 21.2-06) so 21.2-06 / 21.2-08 never re-touch config.ts (avoids a wave merge collision).
