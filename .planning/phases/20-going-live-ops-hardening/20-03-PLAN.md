<objective>
Connect the D-ANTIRUG-LIVE-GATE-CODE 7-day-floor mechanism to the anti-rug detector
runtime: when `startChainAntiRugListener(ctx)` first runs for a chain post-restart,
record the current unix timestamp into `chain_state.antirug_dry_run_started` via the
idempotent `setAntirugDryRunStarted` prepared statement from Plan 20-01. The
`COALESCE` semantics ensure subsequent calls per chain are no-ops — so an operator
restart does NOT reset the timestamp, and the 7-day floor measured by preflight's
`checkAntiRugLiveGate` (Plan 20-02) reflects "time since the FIRST start", not "time
since the LATEST restart".

Purpose: Without this insertion, Plan 20-02's `checkAntiRugLiveGate` would always
read NULL (because no other code writes the column) and would FATAL-exit even when
the operator has been running dry-run mode for weeks. This task gives the live-gate
preflight check a real timestamp to compare against.

Output: One small insertion in `src/anti-rug/detector.ts` `startChainAntiRugListener`
(after the function-entry chain-state-init at lines 565-577) + one new dedicated
unit test verifying first-call records + re-call no-op behavior.
</objective>
