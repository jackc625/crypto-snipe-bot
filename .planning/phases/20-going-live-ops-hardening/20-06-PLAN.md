<objective>
Ship the dashboard pause banner per D-PAUSE-UI: a high-visibility full-bleed red banner
in the dashboard layout that surfaces global pause state with paused_at timestamp,
pausedBy attribution, reason text, and a Resume button. Initial state hydrates via
`GET /api/controls/pause` (Plan 20-05); WS event `pause_state_change` (broadcast from
Plan 20-04 mid-run setInterval + Plan 20-05 POST endpoints) drives live updates.

Visually mirrors the existing `CircuitBreakerBanner.tsx` (Phase 19 Plan 19-06):
same `bg-loss text-white py-3 px-4 mb-4 -mx-4 sm:-mx-6 lg:-mx-8` full-bleed classes,
same `<AlertOctagon>` icon family, same mount position above `<main>` in Layout.tsx.
Operator instantly recognizes "something blocking new trades is happening" — visual
consistency with the anti-rug emergency banner is the locked recommendation per
RESEARCH Open Question 10.

Purpose: Operator visibility. Pause silently flipped via CLI or mid-run setInterval
without visual feedback would defeat D-PAUSE-UI ("high-visibility single control"). The
banner is the dashboard-side fulfillment of D-PAUSE-SHAPE + D-PAUSED-RESTART.

Output: 1 new component (PauseBanner.tsx) + 3 modified hooks/layout/types files +
1 new unit test file covering the banner behavior + Resume click.
</objective>

       ```typescript
       // dashboard/src/components/PauseBanner.tsx
       // Phase 20 / Plan 20-06 / OPS-LIVE-09 D-PAUSE-UI — Full-bleed red banner.
       // Renders when pauseState.paused === true. Visual parity with CircuitBreakerBanner.
       // Resume button POSTs /api/controls/resume; success → WS pause_state_change drives unmount.
       //
       // References:
       //   - .planning/phases/20-going-live-ops-hardening/20-CONTEXT.md D-PAUSE-UI
       //   - dashboard/src/components/anti-rug/CircuitBreakerBanner.tsx (analog)

       import { PauseCircle } from 'lucide-react';
       import { useWs } from '../hooks/WebSocketContext';

       export function PauseBanner() {
         const { pauseState } = useWs();
         if (!pauseState || !pauseState.paused) return null;

         const formatTs = (ts: number | null) =>
           ts ? new Date(ts * 1000).toLocaleString() : 'unknown';

         async function handleResume() {
           try {
             await fetch('/api/controls/resume', { method: 'POST', credentials: 'include' });
             // WS pause_state_change will drive the unmount
           } catch (e) {
             console.error('Resume failed', e);
           }
         }

         return (
           <div className="bg-loss text-white py-3 px-4 mb-4 -mx-4 sm:-mx-6 lg:-mx-8">
             <div className="flex items-start gap-3">
               <PauseCircle className="w-5 h-5 shrink-0 mt-0.5" />
               <div className="flex-1">
                 <h2 className="text-xl font-bold leading-[1.2]">
                   BOT PAUSED — since {formatTs(pauseState.pausedAt)} by {pauseState.pausedBy ?? 'unknown'}
                 </h2>
                 <p className="text-sm mt-1">{pauseState.reason ?? 'No reason provided.'}</p>
                 <button
                   type="button"
                   onClick={handleResume}
                   className="inline-flex items-center gap-2 mt-3 bg-surface-light rounded px-3 py-1 hover:opacity-80 transition-opacity text-accent underline"
                 >
                   Resume
                 </button>
               </div>
             </div>
           </div>
         );
       }
       ```
