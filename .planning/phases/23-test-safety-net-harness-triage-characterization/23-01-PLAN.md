test/realpath/harness/chain.ts:
- installSeams(): void. Idempotent per worker. Throws when the alias or the ws swap did not attach.
- class FakeNode. Constructed with { chainId }. Scenario-facing members:
  handle(body, connection?), the one entry point for every JSON-RPC call: body is one request or a batch, and connection is the { send(text) } object a subscription delivers through, which FakeWebSocket passes as itself and HTTP leaves out;
  setBalance(address, wei); setCode(address, hex); setRead(address, signature, result-or-handler) where signature is the human ABI form such as getAmountsOut(uint256,address[]); setRelay(method, handler);
  failNext(method, { selector?, to?, after?, times?, error? }) returning a fault handle with a fired count, where after is a predicate so the fault arms only once the scenario has reached a stage; hold(method, { selector?, to?, after? }) returning a handle with release() and heldCount, both also accepting relay methods such as eth_sendBundle and flashbots_getBundleStatsV2; mine({ baseFeePerGas?, include? }) returning the new block number, where include names exact hashes; emitLogs(logs) delivering in exactly the given order through the subscribed socket; dropSocket(code?);
  callLog (every JSON-RPC call in arrival order: method, raw params, to, selector, data, block tag), history (every accepted and mined event in order, with hash, nonce, route and block), subscriptions (each entry holds id, kind, filter and connection), submitted (each entry holds raw, hash, parsed Transaction, route, status), relay (each entry holds method, params, url), strays (unknown methods, unknown URLs, unknown reads).
  Plan 23-28 adds setFees, setReceiptLogs, setFutureNoncePolicy, neverMine, the mine options exclude and logs, the replaced and dropped history events, and log storage on emitLogs.
- class FakeWebSocket. Replaces ws.WebSocket: on, once, off, send, ping, terminate, close, readyState, onopen, onmessage, onclose, and a static instances list.
