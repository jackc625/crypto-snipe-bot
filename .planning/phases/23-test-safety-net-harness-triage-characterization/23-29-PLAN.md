- `--check-manifest`: runs nothing. Every `CONVERTED_TESTS` row with `mutants` names only existing mutants, each listing the row's `currentTitle` in `expected`, or for a `WIRING_MUTANTS` entry its `Test NN` number; every mutant in `MUTANTS` and `WIRING_MUTANTS` is named by at least one row, or by the guard exception below; every `removed` row has a non-empty reason; every mutant name is unique; every `find` occurs exactly once in the current target file; and the rows per test file equal `CONVERTED_COUNTS`. It prints `MANIFEST-OK rows <n> files <m> guards <k>`.
- `--check-summaries <path>...`: every mutant named by a row has a `RED-OK <mutant> :: <testFile> :: <currentTitle>` line in those files, every `GUARD_MUTANTS` mutant has a `RED-OK <mutant> :: <testFile> :: <guardedTitle>` line, and every `removed` row has a line beginning `AC-38 removed: <baseTitle>`.

Addresses the plan-check blocker: `main-starts-before-lock` in plan 23-31 proves the lock-before-start order that test (4) of `test/unit/mainEntry.test.ts` asserted as source text. After conversion that order is observed by test (1), a behavior test that never read a file, so it has no `CONVERTED_TESTS` row and no row could list it in `expected`. Dropping the mutant would drop the protection, so `GUARD_MUTANTS` is the one exception to "every mutant is named by a row", and it is narrow. A row is `{ mutant, guardedTitle, convertedTitle, reason }`. `--check-manifest` fails unless all of these hold:
- `mutant` exists in `MUTANTS`, appears in one guard row only, and no `CONVERTED_TESTS` row names it.
- That mutant's `expected` is exactly `[guardedTitle]`.
- `guardedTitle` is a `describe > it` path built from string-literal titles and occurring exactly once in the mutant's `testFile`, read through the TypeScript AST, so a misspelled title fails without a run.
- `guardedTitle` is neither the `currentTitle` nor the `baseTitle` of any `CONVERTED_TESTS` row, because a converted test belongs in its own row.
- `convertedTitle` is the `currentTitle` of a `CONVERTED_TESTS` row with the same `testFile`, so a guard exists only to back one named conversion.
- `reason` is non-empty.

A mutant named by neither a row nor a guard still fails, so a stray or misspelled mutant cannot pass. Guard rows add nothing to `rows` or `files`, and each conversion plan pins `guards <k>` as well, so a new guard cannot appear unnoticed.

The manifest and summary rules are functions taking their tables and file contents as arguments, so they can be proven without running anything. `--self-test` drives them on in-memory tables and temp files and prints `SELF-TEST-OK cases <n>`. Each of these must fail: a row naming a missing mutant, a row with neither `mutants` nor `removed`, a `removed` row with an empty reason, a duplicate mutant name, a `find` occurring zero times and one occurring twice, a mutant no row names and no guard names, a per-file count that differs, a summary missing a `RED-OK` line and a summary missing an `AC-38 removed:` line. So must each guard case: a guard naming a missing mutant, the same mutant in two guard rows, a guard whose mutant a converted row also names, a guard whose mutant's `expected` differs from `[guardedTitle]`, a `guardedTitle` misspelled in both the guard and `expected` so that only the AST check of a temp test file can catch it, a `guardedTitle` that is a converted row's title, a `convertedTitle` that is no row of that test file, an empty `reason`, and a summary missing a guard's `RED-OK` line. A complete table and matching summary must pass, both with no guard and with one guard, and the one-guard table must report `guards 1` with `rows` unchanged.

Add negative rows to `--self-proof`, each with the refusal it must produce, so the runner is shown unable to report a proof that is not one. Each uses `src/guards/directEntry.ts`. `mech-not-applied`: a `find` that does not occur, which must give `NOT-APPLIED`. `mech-not-reached`: `mech-vite`'s run and edit with reach `child`, which must give `NOT-REACHED`, because that test starts no child. `mech-stayed-green`: an edit of the comment `// A file that cannot be resolved still compares by its full path.`, which must give `STAYED-GREEN`. `mech-wrong-set`: `mech-vite`'s run with `expected` naming a different title, which must give `WRONG-SET`. `mech-compile-error`: `mech-child`'s run and `messageIncludes` with the statement replaced by broken syntax, which must give `BAD-FAILURE`, because the child now fails to compile while the same test still fails. A row gives its named refusal or `--self-proof` exits non-zero. It prints `SELF-PROOF-OK rows <n>`.

With the conversion tables empty, `--check-manifest` prints `MANIFEST-OK rows 0 files 0 guards 0`. Plan 23-26 requires the final 36 rows in 11 files and 1 guard, so an empty table can never pass there.
