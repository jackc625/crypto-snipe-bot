Choose tags from what the timeline shows, and cite each by its real finding ID.

Why the update switch is an environment variable: `test/rails/core.cjs` keeps keys matching the `VITEST` prefix through its scrub (`isEssentialKey`), and the npm scripts run through `cmd` on Windows, so a shell assignment in a script would not work. A small Node wrapper sets it, and nothing else does.
