<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator argv -> capture-launch.ts | A token address from the command line is untrusted input that gets baked into a fixture and later drives a fork buy |
| Fixture JSON -> fork replay handler | Fixture addresses drive real handler calls on a fork; a typo could target the wrong contract |
| Archive RPC URL -> capture script | The archive endpoint may carry a credential in the URL (Alchemy key) |
| Fork test signing key -> wallet | The replay signs transactions; it must use the fork-only key, never the prod key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-03-01 | Tampering | capture-launch.ts writing a malicious/typo address into a fixture | mitigate | ethers.getAddress checksum-validation on argv (rejects a malformed/typo address loudly); fixtures are fork-only (no real funds); D-FIXTURE-SELECTION hand-picks known-safe tokens |
| T-21-03-02 | Information Disclosure | Archive RPC URL (Alchemy key in URL) logged or committed | mitigate | The URL is read from env (CAPTURE_ARCHIVE_RPC_URL/ALCHEMY_URL), never hardcoded or written into a fixture; fixtures store only public addresses/blocks; pino logs the slug/blocks, not the RPC URL |
| T-21-03-03 | Tampering / financial loss | Replay test signing with the prod wallet on a real-mainnet RPC | mitigate | requireRealMainnetGate before any tx; FORK_ONLY_TEST_KEY (zero-ETH throwaway) is the only signer; acceptance greps for zero process.env.PRIVATE_KEY; local fork is 31337 |
| T-21-03-04 | Repudiation / masked failure | A replay test asserting success from an op log instead of the DB | mitigate | D-OP-DB-TRUTH: the assertion reads trades.amount_out NOT NULL + the buy/sell rows, never an op log line; hollow fixtures are it.skip not auto-pass (D-04) |
| T-21-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages -- uses already-installed ethers (`6.16.0`), vitest (`^4.1.1`), hardhat (`2.26.0`), @nomicfoundation/hardhat-network-helpers (`^1.1.0`); RESEARCH Package Legitimacy Audit confirms zero installs |
