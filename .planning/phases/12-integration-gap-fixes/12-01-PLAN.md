<objective>
Fix the multi-dex price resolution bug (INT-02) so BSC PancakeSwap V3 positions get the correct quoter address instead of incorrectly matching Uniswap V3's quoter. Add `dex_name` column to trades table, update all insertTrade call sites to store the DEX identity, fix positions.ts to resolve DexConfig by dex_name, and add dex_name to getPnL output.

Purpose: BSC has two V3 DEXes (Uniswap V3 and PancakeSwap V3). The current first-match-by-dexType bug causes PancakeSwap V3 trades to use Uniswap V3's quoter for price queries, returning incorrect prices in the dashboard.

Output: Schema migration v4, updated prepared statements, fixed dex resolution, updated call sites, unit tests, and integration test for /api/positions with BSC V3 dex_name data passing.
</objective>
