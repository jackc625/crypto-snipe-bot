8. **Compute unrealized P&L (D-05):**
   The formula: `unrealizedPnl = unrealizedValue - netCostBasis`
   Where:
   - `netCostBasis = parseFloat(trade.buy_cost || '0') - trade.sell_revenue`
   - For `unrealizedValue`: Since `queryPrice` returns the ETH value of the original buy amount worth of tokens, but after partial sells the remaining tokens are less, scale by remaining fraction:
     - `remainingFraction = 1.0` if no exit state or no original_token_amount
     - If exit state exists and `partial_tiers_completed.length > 0`, compute remaining from partial sell tiers: each tier has a percentage. But simpler: remaining_fraction = 1 - sum of completed tier percentages. However, we don't have the tier config here easily.
     - Simplest correct approach: `unrealizedValue = (currentPrice ?? 0) * remainingFraction` where remainingFraction approximates from `sell_revenue / buy_cost` subtracted from 1. Actually, since `currentPrice` from `queryPrice` represents the value of the *original* buy amount worth of tokens, and partial sells have reduced the actual balance, the unrealized value needs scaling. But `queryPrice(ctx, dex, token, feeTier, buyAmountWei)` queries "how much ETH would I get for `buyAmountWei` worth of tokens" -- it's a *price ratio* not an absolute value. Actually looking at `queryPrice` more carefully: for V2 it calls `router.getAmountsOut(buyAmountWei, path)` and returns `Number(amounts[1])`. So it returns the *wei value* of the output. The price is `currentPrice / buyAmountWei` as a ratio.
     - Correct approach per Pitfall 6: `unrealizedValue = (currentPrice / Number(buyAmountWei)) * remainingTokenValue`. But this is getting complex. Simpler: `priceRatio = currentPrice / Number(ethers.parseEther(trade.buy_cost || '0'))`. Then `unrealizedValue = priceRatio * (parseFloat(trade.buy_cost || '0') - trade.sell_revenue)`. Wait, this isn't right either.
     - ACTUALLY the simplest correct calculation: `unrealizedPnl = (currentPrice != null ? currentPrice / 1e18 : 0) - parseFloat(trade.buy_cost || '0')` when there are NO partial sells. With partial sells: the exit engine is still monitoring the full position, and `currentPrice` represents what you'd get back for the original buy amount. But tokens have been sold via partial sells already. So the actual remaining value is less.
     - Per Research Pitfall 6 recommendation: `unrealizedValue = (currentPrice / 1e18) * (remainingTokens / originalTokenAmount)`. Then `unrealizedPnl = unrealizedValue - (buyCost - sellRevenue)`.
     - `remainingTokens` is not directly available. But we can approximate: if `sell_revenue > 0`, the fraction remaining is roughly `1 - (sell_revenue / (currentPrice/1e18))` if we assume sell prices were similar to current price. This is imprecise.
     - **Simplest robust approach:** Just compute `unrealizedPnl = (currentPrice != null ? currentPrice / 1e18 : 0) - parseFloat(trade.buy_cost || '0') + trade.sell_revenue`. This means: "current value of original tokens + already-received sell revenue - original cost". If some tokens were sold, `currentPrice` overstates remaining value BUT `sell_revenue` already accounts for the received ETH. The error is that `currentPrice` still represents the full original amount, not remaining. For v1, this approximation is acceptable and avoids token balance queries.
     - USE THIS FORMULA: `unrealizedPnl = (currentPrice !== null ? (currentPrice / 1e18) + trade.sell_revenue - parseFloat(trade.buy_cost || '0') - trade.sell_gas : null)`
     - Note: `currentPrice` from `queryPrice` is in wei (Number), so divide by 1e18 to get ETH. `trade.sell_revenue` and `trade.buy_cost` are already in ETH-denominated values.

```typescript
import { Contract } from 'ethers';
import type { ChainContext, DexConfigV2 } from './chainRegistry';
import { PAIR_ABI, FACTORY_ABI, V3_FACTORY_ABI } from './utils/abis';
import { sendTelegramAlert } from './utils/notifier';
import { logger } from './utils/logger';

const log = logger.child({ module: 'alphaDrop' });

/**
 * Multi-chain alpha drop handler.
 * Discovers which DEX the token is on by querying each factory,
 * then routes to the appropriate handleNewPairForChain or handleNewV3PoolForChain.
 */
export async function handleAlphaDropForChain(ctx: ChainContext, tokenAddress: string): Promise<void> {
    try {
        // Try each V2 DEX factory to find the pair
        for (const dex of ctx.chain.dexes) {
            if (dex.dexType === 'v2') {
                const factory = new Contract(dex.factoryAddress, FACTORY_ABI, ctx.httpProvider);
                const pairAddress = await factory.getPair(tokenAddress, ctx.chain.wethAddress);
                if (pairAddress && pairAddress !== '0x0000000000000000000000000000000000000000') {
                    const pair = new Contract(pairAddress, PAIR_ABI, ctx.httpProvider);
                    const token0 = await pair.token0();
                    const token1 = await pair.token1();
                    // Import handleNewPairForChain from bot.ts
                    const { handleNewPairForChain } = await import('./bot');
                    await handleNewPairForChain(ctx, dex as DexConfigV2, token0, token1, pairAddress);
                    return;
                }
            }
            // V3: check if pool exists for common fee tiers
            if (dex.dexType === 'v3') {
                const v3Factory = new Contract(dex.factoryAddress, V3_FACTORY_ABI, ctx.httpProvider);
                for (const feeTier of [500, 3000, 10000]) {
                    const pool = await v3Factory.getPool(tokenAddress, ctx.chain.wethAddress, feeTier);
                    if (pool && pool !== '0x0000000000000000000000000000000000000000') {
                        const { handleNewV3PoolForChain } = await import('./bot');
                        await handleNewV3PoolForChain(ctx, dex, tokenAddress, ctx.chain.wethAddress, feeTier, pool, 0);
                        return;
                    }
                }
            }
        }
        log.warn({ token: tokenAddress, chain: ctx.chain.name }, 'No pair/pool found on any DEX for chain');
        await sendTelegramAlert(`${ctx.chain.displayName} No pair found for \`${tokenAddress}\``);
    } catch (e) {
        log.error({ err: e, token: tokenAddress, chain: ctx.chain.name }, 'Error in handleAlphaDropForChain');
        await sendTelegramAlert(`${ctx.chain.displayName} Error handling drop for \`${tokenAddress}\``);
    }
}
```
