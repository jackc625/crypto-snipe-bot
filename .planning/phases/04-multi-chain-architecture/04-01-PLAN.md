**`buildChainRegistry()` function:**
1. Read `ENABLED_CHAINS` from `process.env` (default: 'eth'). Split by comma, trim, lowercase.
2. For each enabled chain name, look up the static chain template defined above.
3. Populate RPC URLs from env vars (e.g., `ETH_RPC_URL`, `BSC_RPC_URL`). If httpRpcUrl is missing for an enabled chain, log fatal and exit.
4. Populate `snipeAmount` and `maxCapital` from env vars with defaults (per D-08, D-09).
5. Set `enabled: true` for chains in ENABLED_CHAINS, `enabled: false` for others.
6. Return the full registry as `Map<string, ChainConfig>` keyed by chain name.

**`getEnabledChains()` function:**
Return array of ChainConfig where `enabled === true`.

**`createChainContext(chain: ChainConfig)` function:**
1. Call `getProvider(chain.name, chain.httpRpcUrl)` to get/create HTTP provider.
2. Call `getWsProvider(chain.name, chain.wsRpcUrl, chain.chainId)` to get WebSocket provider (null if no wsRpcUrl).
3. Create `Wallet` from `process.env.PRIVATE_KEY` connected to HTTP provider.
4. Create pino child logger: `logger.child({ chain: chain.name })`.
5. Return `ChainContext` object.

**Validation in `buildChainRegistry()`:**
- If ENABLED_CHAINS contains unknown chain name, log fatal and exit.
- If enabled chain has no RPC URL, log fatal and exit.
- If ETH is enabled and FLASHBOTS_AUTH_KEY is missing, log fatal and exit.
- If BSC is enabled and BLOXROUTE_AUTH_HEADER is missing, log fatal and exit.

Use `import { logger } from './utils/logger';` for all logging. Follow existing codebase patterns: named exports, camelCase file, structured pino logging.

**Extend `src/utils/provider.ts`:**

Add WebSocket provider support (per D-04):

```typescript
import { ethers, JsonRpcProvider, WebSocketProvider, Wallet } from 'ethers';
import { CONFIG } from '../config';

const httpProviders = new Map<string, JsonRpcProvider>();
const wsProviders = new Map<string, WebSocketProvider>();

export function getProvider(network?: string, rpcUrl?: string): JsonRpcProvider {
    const key = network || CONFIG.network;
    let provider = httpProviders.get(key);
    if (!provider) {
        const url = rpcUrl || CONFIG.rpc[key as keyof typeof CONFIG.rpc];
        if (!url) throw new Error(`No RPC URL configured for network: ${key}`);
        provider = new ethers.JsonRpcProvider(url);
        httpProviders.set(key, provider);
    }
    return provider;
}

export function getWsProvider(network: string, wsUrl: string | null, chainId?: number): WebSocketProvider | null {
    if (!wsUrl) return null;
    let provider = wsProviders.get(network);
    if (!provider) {
        provider = new ethers.WebSocketProvider(wsUrl, chainId);
        wsProviders.set(network, provider);
    }
    return provider;
}

export function removeWsProvider(network: string): void {
    const provider = wsProviders.get(network);
    if (provider) {
        provider.destroy();
        wsProviders.delete(network);
    }
}

export function getWallet(network?: string, rpcUrl?: string): Wallet {
    return new ethers.Wallet(CONFIG.walletPrivateKey, getProvider(network, rpcUrl));
}
```

Keep backward compatibility: existing `getProvider()` and `getWallet()` calls without arguments still work via CONFIG.network.
