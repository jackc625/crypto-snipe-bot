## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env file → process.env | operator-supplied secrets/config cross into the bot at startup; invalid values must FATAL-exit rather than continue with unknown state |
| hardcoded allowlist constants in source | source-of-truth lockers ship in git history; any typo becomes a silent allowlist hole (EOA pass-through) that the dry-run getCode() check (Plan 19-03) catches at startup |
| `<PREFIX>_ANTIRUG_ALLOWLIST_EXTRA` operator overlay | operator-supplied locker addresses cross from .env into the merged allowlist; bypass of the hardcoded base is by design (D-LIST-SOURCE) but each entry must still pass getCode() check (Plan 19-03) |
