# Phase 21.3 Plan 01: Buy-Leg Calm-Gas Private Inclusion Hardening Summary

## Accomplishments

- **Task 1 — flashbots.ts multi-builder + multi-block + telemetry (`1685f54`):**
  - `rawSendBundle` module helper: builds `{ method:'eth_sendBundle', params:[{ txs, blockNumber:hex, builders }], id, jsonrpc:'2.0' }`, signs the body with the exact `${address}:${signMessage(id(body))}` X-Flashbots-Signature scheme the library uses (verified against index.js:793-797 via ethers v6 `FetchRequest` + `id`), `assertOk`s, returns `{ bundleHash?, error? }`.
  - Submit closure rewritten: `signBundle` ONCE → `simulate(block+1)` (kept) → loop `rawSendBundle` over `block+1 .. block+MEV_BUY_TARGET_BLOCKS` (clamped 1..8) with the SAME `signedBundle` bytes and the parsed `MEV_BUILDERS` list → KEEP library `sendBundle(block+1)` as the native-confirm + deterministic-hash source → KEEP `bundle.wait()` / `:178-182` real-hash extraction / `:190-211` nativeConfirmed verbatim.
  - `op:'flashbots.bundle.stats'` telemetry from `getBundleStatsV2(bundle.bundleHash, block+1)`: logs `consideredByBuilders`/`sealedByBuilders` pubkeys + `isSimulated`/`isHighPriority`, NO auth key, NO signed raw tx; best-effort (a stats-query failure warns and never fails the submit).
  - `MEV_BUILDERS` parsed comma-split/trimmed/non-empty with a verified-registry default fallback; `MEV_BUY_TARGET_BLOCKS` via a never-NaN/never-negative clamp helper (default 3, 1..8).
  - Flipped the 3 `flashbotsMultiBuilder.test.ts` Wave-0 `it.skip` stubs to real WIRE-BODY assertions (+1 builders-override case) — asserts `params[0].builders` equals the configured array (contains `beaverbuild.org` + `Titan`), the same `params[0].txs` bytes across N ascending `blockNumber` hexes with `signBundle` called once, and the telemetry log shape with no secret leakage.

- **Task 2 — reconciliation.ts independent buy ceiling (`ddfbdd0`):**
  - Added `buyMaxPriorityFeeGwei: 25` to `MEV_RECONCILE_DEFAULTS`; the `'buy'` branch of the `ceilingGwei` ternary now reads `parsePositiveNumber(env.MEV_BUY_MAX_PRIORITY_FEE_GWEI, 25)`, INDEPENDENT of the legacy `MEV_MAX_PRIORITY_FEE_GWEI` (default 5, retained as the documented backward-compat floor reference) and of the sell ceiling.   - `computePublicExitReserveWei` and the `computeAffordablePriorityFee` clamp (`min(ceiling, affordabilityBound)`) are byte-unchanged — the raise is INPUT-only.
  - Extended `inclusionReconciliationConfig.test.ts` with the 4 buy-leg cases: default 25 / override 40 / malformed (`-7` and `not-a-number`) → 25 / clamp-still-binds on a thin wallet (submitted fee = the 6-gwei affordability bound, NOT the 25-gwei ceiling) + an independence assertion.
