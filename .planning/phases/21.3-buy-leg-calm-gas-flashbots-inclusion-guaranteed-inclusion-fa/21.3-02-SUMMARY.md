# Phase 21.3 / Plan 02: Mode-Aware Buy-Time Entry-Affordability Gate Summary

**Made `checkEntryExitAffordability` mode-aware (STOP-THE-LINE-05-C / D-BUY-AFFORDABILITY-EXTEND): a DELIBERATE buy now reserves its OWN worst-case public-fallback buy gas (reusing the single-source `computeWorstCasePublicExitGas` with `approvalGasLimit:0n` + `DELIBERATE_BUY_GAS_BUFFER`), while a genuine SNIPE reserves ZERO public-buy gas it will never use — the snipe floor is byte-for-byte the 21.2 floor and the fail-closed-on-RPC-error posture is preserved for both modes.**

## What Changed

### `src/preflight.ts`
- `checkEntryExitAffordability(chain, mode: 'snipe' | 'deliberate' = 'snipe')` — added the optional `mode` param defaulting to `'snipe'` so bot.ts and every current caller are unchanged until plan 03 threads the deliberate mode through.
- New `worstCasePublicBuyGas` term inside the `try`, computed after `worstCasePublicSellGas`:
  - `mode === 'deliberate'` → `computeWorstCasePublicExitGas({ baseFeeWei, sellGasLimit: chain.gas.maxGasLimit, approvalGasLimit: 0n, sellGasBuffer: parseDeliberateBuyBuffer() })` (the buy needs no ERC-20 approve, hence `approvalGasLimit: 0n`).
  - `mode === 'snipe'` → `0n` (a genuine snipe has no public fallback to reserve for).
- Folded `worstCasePublicBuyGas` into the `floor` sum: `snipeValue + worstCaseBuyGas + worstCasePublicSellGas + worstCasePublicBuyGas + cushion`. In snipe mode the added term is `0n`, so the floor equals the 21.2 floor byte-for-byte.
- `mode` + `worstCasePublicBuyGas` surfaced in the `reason` string and the `details` object on every return path (passing/failing, the no-usable-fee-data branch, and the fail-closed catch).
- Added `DELIBERATE_BUY_GAS_BUFFER_DEFAULT = 2.0` constant and a `parseDeliberateBuyBuffer()` never-NaN/never-≤0 helper mirroring the existing `parseExitGateBuffer()`.

### `test/unit/preflight/exitAffordability.test.ts`
- Added a `deliberateBuyReserveWei(chain, buffer)` helper computing the extra public-buy reserve exactly (`maxGasLimit × (baseFee × buffer)`, approvalGas = 0).
- New `describe('mode-aware public-BUY reserve …')` block with 5 tests:
  - **Test 5 (deliberate reserves / snipe exempt):** the SAME balance funded exactly at the snipe floor PASSES `mode='snipe'` (and the default) but FAILS `mode='deliberate'` — proves the extra reserve is real.
  - **Test 6 (term surfaced):** `deliberate` `details.worstCasePublicBuyGas > 0` (and equals the single-source `deliberateBuyReserveWei`), `snipe` term is `0`; `details.mode` is correct in each.
  - **Test 7 (buffer controls the reserve):** a larger `DELIBERATE_BUY_GAS_BUFFER` (3.0 vs 2.0) raises the deliberate floor — the same balance at the default-buffer floor now FAILS, and the surfaced term grows to `deliberateBuyReserveWei(chain, 3.0)`.
  - **Test 8 (no snipe regression):** the snipe-mode floor (and its exact-wei boundary) equals the pre-21.3 floor exactly — at-floor passes, one-wei-below refuses.
  - **Test 9 (fail-closed preserved in deliberate):** a balance fetch that throws REFUSES in deliberate mode too.
