## Sampling Rate

- **After every task commit:** Run `npx vitest run --project unit <changed test file(s)>`
- **After every plan wave:** Run `npx vitest run --project unit --project integration`
- **Before `/gsd-verify-work`:** Full suite `npx vitest run` green, THEN the fork rehearsal
  `npx vitest run --project fork` green (D-FORK-REHEARSAL), BEFORE the 21-07 real-capital retry resumes.
- **Max feedback latency:** ~60s (unit); fork is network-bound (per-wave / phase-gate only).
- **Real-capital closure:** per D-EVIDENCE-BAR the calm-gas private buy inclusion + the deliberate
  private→public buy transition close ONLY on the Phase-21 21-07 live retry artifacts (Etherscan
  hash / DB / pino excerpt). A fork has no Flashbots relay — the multi-builder/private→public
  mechanics are unit/mock-proven; the fork proves the surrounding buy→register→monitor wiring.
  Opportunistic multi-builder live confirmation rides the NEXT real snipe via `getBundleStatsV2`
  telemetry (D-EVIDENCE-BUY-INCLUSION) — NOT a gated real-capital snipe.
