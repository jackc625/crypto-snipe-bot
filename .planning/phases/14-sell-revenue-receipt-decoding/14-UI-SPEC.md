## Phase Classification: Backend-Only

Phase 14 (Sell Revenue Receipt Decoding) has **zero frontend surface area**. All changes are backend-only:

1. New `src/utils/receiptDecoder.ts` helper (receipt parsing logic)
2. Modified `src/exitEngine.ts` (two functions: executeFullSell, executePartialSell)
3. Optional fix to `src/utils/mevStrategies/flashbots.ts` (return real tx hash)
4. New unit tests in `test/unit/receiptDecoder.test.ts`

The dashboard already handles both null and non-null `amount_out` values:
- P&L queries use `CAST(COALESCE(s.amount_out, '0') AS REAL)` -- null-safe
- `formatPnL()` accepts `number | null` and displays `--` for null
- `pnlColor()` returns neutral color for null values
- PositionTable uses `pos.unrealizedPnl ?? pos.pnl ?? 0` fallback chain

When Phase 14 populates `amount_out` with real values, all dashboard views (Overview P&L, Trade History, Risk & Exposure) will automatically display correct data without any UI changes.

**No new components, no modified components, no new pages, no styling changes.**
