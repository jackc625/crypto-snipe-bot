<!-- Complete v5-to-v6 API migration map for this codebase -->

Import changes:
```typescript
// v5: import { providers, BigNumber, Wallet, Contract, utils } from "ethers"
// v6: import { JsonRpcProvider, Wallet, Contract, ethers } from "ethers"
//     OR: import { ethers } from "ethers" and use ethers.JsonRpcProvider etc.

// v5: import type { TransactionRequest } from "@ethersproject/abstract-provider"
// v6: import type { TransactionRequest } from "ethers"

// v5: providers.JsonRpcProvider (as type parameter)
// v6: JsonRpcProvider (flat import)
```

BigNumber-to-BigInt patterns:
```typescript
// v5: BigNumber.from(x) → v6: BigInt(x) or xn literal
// v5: .mul(x) → v6: * BigInt(x)
// v5: .div(x) → v6: / BigInt(x)
// v5: .sub(x) → v6: - x
// v5: .add(x) → v6: + x
// v5: .eq(x) → v6: === x
// v5: .gt(x) → v6: > x
// v5: .lt(x) → v6: < x
// v5: .isZero() → v6: === 0n
// v5: ethers.constants.Zero → v6: 0n
```

Utility moves:
```typescript
// v5: ethers.utils.parseEther(x) → v6: ethers.parseEther(x)
// v5: ethers.utils.parseUnits(x,d) → v6: ethers.parseUnits(x,d)
// v5: ethers.utils.formatEther(x) → v6: ethers.formatEther(x)
// v5: new ethers.utils.Interface(abi) → v6: new ethers.Interface(abi)
```

Provider changes:
```typescript
// v5: new ethers.providers.JsonRpcProvider(url) → v6: new ethers.JsonRpcProvider(url)
// v5: provider.getGasPrice() → v6: (await provider.getFeeData()).gasPrice
// v5: (await provider.getNetwork()).chainId → same but returns bigint in v6
```

Contract changes:
```typescript
// v5: contract.callStatic.method(args) → v6: contract.method.staticCall(args)
// v5: contract.address → v6: contract.target as string (for known-address contracts)
// v5: await contract.deployed() → v6: await contract.waitForDeployment()
// v5: await contract.getAddress() → same in v6 (returns string)
```

Type annotation changes:
```typescript
// v5: ethers.BigNumber → v6: bigint
// v5: providers.JsonRpcProvider → v6: JsonRpcProvider
```
