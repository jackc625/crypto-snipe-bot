    Create `src/api/routes/controls.ts`:
    - Export `controlRoutes(contexts: ChainContext[]): Router`

    - POST '/force-sell/:tradeId' handler (per D-16, Pitfall 3 from RESEARCH.md):
      - Parse tradeId from params as integer
      - Query DB for the trade: `db.prepare('SELECT token, chain, pool_type, fee_tier FROM trades WHERE id = ? AND status = ? AND action = ?').get(tradeId, 'pending', 'buy')`
      - If not found: 404 with `{ error: 'Trade not found or already closed' }`
      - Find ChainContext by chain name from trade record
      - If no context: 500 with `{ error: 'Chain not available' }`
      - Find appropriate DexConfig from ctx.chain.dexes matching pool_type and fee_tier
      - **Critical sell safety sequence** per Pitfall 3:
        1. `clearAllTimersForToken(trade.chain, trade.token)` -- stop exit monitor first to eliminate race
        2. `const locked = tryAcquireSellLock(trade.chain, trade.token)` -- acquire mutex
        3. If not locked: 409 with `{ error: 'Sell already in progress for this position' }`
        4. Try: `await executeFullSell(ctx, trade.token, dex, tradeId)`
        5. Finally: `releaseSellLock(trade.chain, trade.token)`
      - On success: `{ ok: true, tradeId, token: trade.token, chain: trade.chain }`
      - On sell failure: 500 with `{ error: 'Force sell failed: ' + err.message }` (per UI-SPEC error state copy)
      - Log all steps via logger child

    - POST '/emergency-sell' handler (per D-15):
      - Query ALL pending positions: `db.prepare('SELECT id, token, chain, pool_type, fee_tier FROM trades WHERE status = ? AND action = ?').all('pending', 'buy')`
      - If no positions: 200 with `{ ok: true, sold: 0, failed: 0, message: 'No open positions to sell' }`
      - Iterate all positions, for each:
        1. Find ChainContext
        2. Find DexConfig
        3. clearAllTimersForToken
        4. tryAcquireSellLock
        5. If locked: executeFullSell, catch errors, releaseSellLock in finally
        6. Track successes and failures with error details
      - Return: `{ ok: failures === 0, sold: successes, failed: failures, errors: [...errorDetails] }`
      - Per UI-SPEC error state: "Emergency sell encountered errors. {N} of {total} positions may not have been sold. Check the bot logs immediately."
      - Use Promise.allSettled or sequential execution (sequential is safer for sell mutex management)

    Update `src/api/server.ts` to mount control routes:

    - Add to apiRouter (after existing data routes):
