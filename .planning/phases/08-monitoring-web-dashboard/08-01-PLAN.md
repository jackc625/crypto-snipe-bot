  <action>
    Create `src/api/middleware/errorHandler.ts`:
    - `asyncHandler(fn)`: wraps async Express handlers in try/catch, calls next(err) on failure
    - `errorMiddleware(err, req, res, next)`: Express error middleware that logs via pino child logger and returns `{ error: string }` with appropriate status code (default 500)
    - Import logger from `../../utils/logger`

    Create `src/api/middleware/auth.ts`:
    - `sessions` Map<string, { createdAt: number }> (module-level, in-memory)
    - `SESSION_TTL_MS = 24 * 60 * 60 * 1000` (24 hours)
    - `loginHandler(req, res)`: validates `req.body.apiKey` against `process.env.DASHBOARD_API_KEY`. On match: generate UUID v4 session token, store in sessions Map, set httpOnly cookie named 'session' with sameSite='strict', maxAge=SESSION_TTL_MS, secure only when NODE_ENV==='production'. Return `{ ok: true }`. On mismatch: return 401 with `{ error: 'Invalid API key. Check DASHBOARD_API_KEY in your .env file.' }` (exact copy per UI-SPEC Copywriting Contract)
    - `authMiddleware(req, res, next)`: reads `req.cookies?.session`, looks up in sessions Map, checks TTL. If invalid/expired: 401 with `{ error: 'Unauthorized' }`. Otherwise next()
    - `validateSession(token: string): boolean`: exported for WebSocket handler to reuse
    - Export `sessions` Map for WebSocket handler access (or export validateSession)

    Create `src/api/routes/health.ts`:
    - Export `healthRoutes(contexts: ChainContext[]): Router`
    - GET '/' handler (per D-20 unauthenticated, per D-29 comprehensive, per D-30 status codes):
      - Map over contexts, try `ctx.httpProvider.getBlockNumber()` for each. Connected if succeeds, disconnected if throws
      - Check wsProvider !== null for wsConnected field
      - Query `getOpenPositionCount.get()` for open position count
      - Query `getPortfolioExposure()` for exposure data
      - Compute 24h P&L by calling `getPnL({ fromTimestamp: Date.now() - 86400000 })` and summing realized_pnl
      - If any chain disconnected: HTTP 503, status='degraded'. Else: HTTP 200, status='ok'
      - Response shape: `{ status, uptime, chains: [{name, displayName, connected, latestBlock, wsConnected}], positions: {open, totalExposure, dailyPnL}, version: require('../../package.json').version }`

    Create `src/api/routes/auth.ts`:
    - Export `authRoutes(): Router`
    - POST '/login' -> loginHandler

    Create `src/api/ws/broadcaster.ts`:
    - `authenticatedClients` Set<WebSocket> (module-level)
    - `addClient(ws)`: add to set, on 'close' remove from set
    - `removeClient(ws)`: remove from set
    - `getClientCount()`: return set size
    - `broadcast(type: string, data: unknown)`: JSON.stringify `{ type, data, timestamp: Date.now() }`, send to all OPEN clients. Skip if no clients. Per D-43 typed JSON events
    - Named exports for all functions

    Create `src/api/ws/handler.ts`:
    - Export `handleUpgrade(wss: WebSocketServer, sessions: Map<string, {createdAt: number}>)`: returns a function `(req, socket, head)` for the HTTP server 'upgrade' event
    - Parse cookies from `req.headers.cookie` manually (cookie-parser doesn't run on upgrade)
    - Validate session token against sessions Map (check TTL)
    - If invalid: write '401' to socket, destroy. If valid: `wss.handleUpgrade(req, socket, head, (ws) => { addClient(ws); wss.emit('connection', ws, req); })`
    - The upgrade handler should accept connections on path '/ws' only

    Create `src/api/server.ts`:
    - Export `startApiServer(contexts: ChainContext[]): { close: () => void }`
    - Create Express app, HTTP server via `createServer(app)`, WebSocketServer attached to HTTP server with `noServer: true`
    - Middleware order (per Pitfall 8 from RESEARCH.md):
      1. `express.json()`
      2. `cookieParser()`
      3. `helmet({ contentSecurityPolicy: false })` (CSP off for SPA inline scripts)
      4. `cors({ origin: true, credentials: true })` (for Vite dev proxy)
    - Route order (per Pitfall 8):
      1. `app.use('/health', healthRoutes(contexts))`
      2. `app.use('/api/auth', authRoutes())`
      3. `app.use('/api', authMiddleware, ...)` -- placeholder for data/control routes from Plans 02/03
      4. Static file serving: `express.static(path.join(process.cwd(), 'dashboard', 'dist'))`
      5. SPA catch-all: `app.get('*', (req, res) => res.sendFile(path.join(process.cwd(), 'dashboard', 'dist', 'index.html')))` wrapped in try/catch (file may not exist during dev)
      6. Error middleware last
    - WebSocket upgrade via `server.on('upgrade', handleUpgrade(wss, sessions))` per Pitfall 1
    - Position broadcast interval: `setInterval(() => { ... }, 5000)` per D-09. Queries positions from db, calls broadcast('positions_update', positionData). Include chain statuses too.
    - Host/port from `process.env.DASHBOARD_HOST || '127.0.0.1'` and `parseInt(process.env.DASHBOARD_PORT || '8080', 10)` per D-19/D-21
    - Log server start via pino child logger `{ module: 'api' }`
    - Return object with `close()` method that clears interval, closes wss, closes server
    - Use logger from `../../utils/logger`
