# Phase 8 — UI Design Contract

> Visual and interaction contract for the monitoring web dashboard. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind CSS v4 utility classes with custom @theme tokens) |
| Preset | not applicable |
| Component library | none (hand-built React components -- single-operator dashboard, small surface area) |
| Icon library | Lucide React (`lucide-react` -- tree-shakeable, 1000+ icons, MIT license, pairs with Tailwind) |
| Font (body) | `Inter` via Google Fonts CDN, fallback to system sans-serif stack (`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`) |
| Font (mono) | `JetBrains Mono` via Google Fonts CDN, fallback to `ui-monospace, 'Cascadia Code', 'Fira Code', monospace` |

**Source:** D-04 (Tailwind CSS), D-06 (dark theme only), RESEARCH.md (React 19 + Vite 8 + Tailwind CSS v4)

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline badge padding |
| sm | 8px | Compact element spacing, table cell vertical padding |
| md | 16px | Default element spacing, card internal padding |
| lg | 24px | Section padding, sidebar item height padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Page-level vertical breaks, sidebar width collapsed (icon rail) |
| 3xl | 64px | Sidebar expanded width offset |

Exceptions:
- Sidebar expanded width: 240px (not a spacing token -- fixed layout dimension)
- Sidebar collapsed width: 56px (icon rail with 48px content + 4px each side)
- Stat card minimum width: 200px
- Table row minimum height: 44px (touch target compliance)
- Confirmation dialog width: 400px

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px | 400 (regular) | 1.5 | Inter | Table cells, descriptions, feed items, config values |
| Label | 12px | 500 (medium) | 1.4 | Inter | Stat card labels, table headers, filter chip text, axis labels |
| Heading | 20px | 600 (semibold) | 1.2 | Inter | Page titles, section headers, dialog titles |
| Display | 28px | 700 (bold) | 1.1 | Inter | Stat card values (total P&L, position count, exposure) |
| Mono | 14px | 400 (regular) | 1.5 | JetBrains Mono | Token addresses, transaction hashes, numeric P&L values, prices |

**Note:** Font weights used are 400, 500, 600, and 700. The Display role uses 700 for visual hierarchy on dashboard stat cards. Label uses 500 for subtle emphasis over body text.

## Interaction Contracts

### Navigation

- Sidebar always visible (no hamburger menu -- desktop-only single-operator tool)
- Sidebar collapsed state persisted in `localStorage`
- Active page indicated by accent-colored left border on sidebar item
- Page transitions are instant (React Router client-side navigation)

### WebSocket Connection

- Connection indicator in sidebar footer: green dot + "Connected" or red dot + "Reconnecting..."
- Auto-reconnect with 3-second delay on disconnect
- On reconnect: full state refresh (positions, chain status) via REST, then resume WebSocket push
- No data loss during brief disconnects -- next push delivers current state

### Position Table Expansion

- Click anywhere on row to toggle expansion (except action buttons)
- Only one row expanded at a time (accordion pattern)
- Expanded section slides down with 150ms ease-out transition
- Force Sell button appears only in expanded section

### Destructive Action Flow

- All destructive buttons are `loss` red background with white text
- Single confirmation: Stop Chain, Start Chain, Force Sell (standard ConfirmDialog)
- Double confirmation: Emergency Sell All (EmergencyConfirmDialog with text input)
- Confirm button in dialog matches the destructive color
- Cancel is always available and always safe

### Loading States

- Initial page load: centered spinner (accent-colored) with "Loading..." text
- Table loading: skeleton rows (surface-lighter pulsing rectangles) matching row height
- Chart loading: chart container with centered spinner
- API errors: inline error banner (loss-colored left border) with retry button

### Responsive Behavior

- Minimum supported viewport: 1024px wide (desktop monitoring use case)
- Below 1024px: horizontal scroll rather than responsive reflow
- Sidebar collapse is the primary space-saving mechanism
