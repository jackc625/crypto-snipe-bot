Trades API (Plan 02):
```typescript
GET /api/trades?chain=eth&from=2026-03-01&to=2026-03-26&outcome=profit&page=1&limit=25
-> {
  trades: Array<{ token, chain, pnl, buyCost, buyGas, sellRevenue, sellGas, buyTime, sellTime, durationHeld, poolType, feeTier }>,
  pagination: { page, limit, total, totalPages }
}
GET /api/trades/export?chain=eth&from=...&to=... -> CSV file download
```

Risk API (Plan 02):
```typescript
GET /api/risk/exposure -> { total: number, byChain: { eth: 1.5, bsc: 1.0, ... } }
GET /api/risk/pnl?range=7d -> { dataPoints: Array<{ time: number, value: number }>, range: string }
GET /api/risk/limits -> { positionLimit: { used, max }, exposureLimit: { used, max }, dailyLoss: { used, limitPct } }
```

Chains API (Plan 03):
```typescript
GET /api/chains -> { chains: Array<{ name, displayName, status, config: { snipeParams, riskLimits, exitStrategy, connection } }> }
POST /api/chains/:name/stop -> { ok, chain, status }
POST /api/chains/:name/start -> { ok, chain, status }
```

Controls API (Plan 03):
```typescript
POST /api/controls/force-sell/:tradeId -> { ok, tradeId, token, chain }
POST /api/controls/emergency-sell -> { ok, sold, failed, errors }
```
